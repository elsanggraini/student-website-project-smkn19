# Project Website SMKN 19 Jakarta

## 📌 Deskripsi
Repository ini berisi project website yang dibuat sebagai bagian dari tugas sekolah di SMKN 19 Jakarta.  
Website ini bertujuan untuk memenuhi kebutuhan pembelajaran serta melatih kemampuan dasar pengembangan web.

## 🛠️ Teknologi yang Digunakan
- HTML
- CSS


## 📂 Struktur Project
- index.html – Halaman utama website  
- css/ – File styling    
- assets/ – Gambar dan media pendukung

## 🚀 Cara Menjalankan Project
1. Download atau clone repository ini
2. Buka file index.html menggunakan browser
3. Website siap digunakan
